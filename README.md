# 🍹 TropiBlend - Premium E-Commerce Landing Page

![TropiBlend Preview](https://images.unsplash.com/photo-1505252585461-04db1eb84625?w=1200&auto=format&fit=crop)

**TropiBlend** is a highly modern, VIP e-commerce landing page designed for a premium organic smoothie and juice brand. It is built focusing on advanced UI/UX principles, featuring a stunning tropical aesthetic, real frosted glassmorphism, and smooth scroll animations.

### 🌐 Live Demo
👉 **[Click here to view the live website](https://muhammadansabarain-eng.github.io/Tropi-Blend/)**

### ✨ Key Features
- **Real Glassmorphism UI:** Advanced frosted glass navigation and overlay effects.
- **Floating Bento Box Grid:** Interactive, floating 3D bento boxes with rich pastel-vibrant gradients.
- **Interactive Shopping Cart:** Fully functional floating sidebar cart drawer with dynamic calculation.
- **VIP Tropical Theme:** Warm, sun-kissed organic aesthetic that feels luxurious and fresh.
- **Fully Responsive:** Perfectly optimized for all devices (Desktops, Tablets, and Mobile phones).

### 🛠️ Technologies Used
- **HTML5:** Semantic and clean markup.
- **CSS3:** Advanced styling, animations, flexbox/grid, and glassmorphism filters.
- **Vanilla JavaScript:** DOM manipulation, cart functionality, and dynamic user interactions.
